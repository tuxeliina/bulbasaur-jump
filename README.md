# bulbasaur-jump
Bulbasaur wants to jump rope, can you help it jump as much as possible?
![GIF of the gameplay loop](/media/img/bulbasaur-jumping.gif)

## Purpose
This was a programming task that I was given in one of my courses and we were tasked with creating a 2D game from scratch using the Gosu library. This game is the result of that. There is no other purpose than that. Hope you enjoy it.
